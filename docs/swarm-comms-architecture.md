# 低空集群：通信分层、机载自治与数据分拣（设计文档）

> 适用范围：**民用低空经济**（工业巡检/应急/物流为生产力主线；灯光表演为娱乐线，单列但**不投入 AI 算力预算**）。
> 本文只定义**架构、分层与口径**，不改主工程依赖；模型/推理仍走既有外部契约
> （`docs/external-vision-inference.md`：`POST image/jpeg → [{kind,confidence,u,v}]`），
> **主工程不内嵌 onnxruntime/tensorflow/opencv**。
> 军事系统（如“战颅”类辅助决策）的公开概念只作**思想参照**，本文**不涉及任何杀伤性/军事能力**。

## 1. 两类场景，两条技术路线（先分清，避免成本失控）

| 维度 | **表演型（几百架）** | **工业型（几~几十架）** |
|---|---|---|
| 目标 | 灯光/编队表演（娱乐，价值有限） | **生产力**：巡检/测绘/应急/物流 |
| 控制形态 | **集中式**：上位机编舞 + GPS/RTK 时间同步 + 预设轨迹 | **分布式**：多跳自组网 + 机载自治 |
| 每机 AI | **不需要**（收同步信号、跑预设轨迹即可） | **需要**（感知/局部决策/数据分拣） |
| 成本敏感点 | 机载算力**越便宜越好** | 小模型 + 通信模块 + 性价比 |
| 在 NexusSky 的落点 | `show`/`FormationService`/`MusicSync` 已具备基础 | `commadapt`/`satlink`/`vision`/`mission` 扩展 |

**结论**：把预算集中在工业线；表演线只做**兼容性**（能接入统一通信/调度面即可），不为其上机载模型。

## 2. 通信分层（LAN → 4/5G → Mesh → 卫星）

按"能省则省"排序，默认优先最便宜可用的层：

| 层 | 公网 | 成本量级（**以实际采购为准**） | 带宽/延迟量级 | 角色 |
|---|---|---|---|---|
| **L0 纯局域网**（Wi-Fi/有线地面网） | 否 | 最低（已有设备） | 高带宽/低延迟（视距内） | **默认主力**：机场/地面站/近场作业 |
| **L1 4G/5G**（有基站） | 是 | 中（流量按量） | 中带宽/中延迟 | 超视距可联网时；**按量计费，不包月浪费** |
| **L2 Mesh 多跳自组网** | 否 | 低（多一跳硬件） | 每跳带宽衰减/延迟累积 | 无基站延伸覆盖；中继用低成本节点/系留 |
| **L3 卫星**（LEO 宽带 / 北斗短报文） | 否（天基） | **最高**（终端+流量） | 窄带（短报文≈文本）/ LEO 宽带但延迟 20ms+ | **保底**：只传事件/摘要/坐标，不传视频 |

**切换与降级**：链路质量低于 SLA（带宽/延迟/抖动）→ 自动从 L0 逐级回落；L2 仍不通 → 进入**迟延容忍（DTN）模式**：机载自治 + 存储，回连后按优先级增量补传。

**SLA 建议口径**（待实测标定，非承诺值）：
- 实时遥测/控制：RTT < 200ms、可用率 > 99%；
- 结构化检测结果：带宽 Kbps 级/机；
- 原始视频：**默认不回传**，按需调取（带宽 Mbps 级/机）。

## 3. 每机部署什么（便宜优先）

| 层 | 工业线 | 表演线 |
|---|---|---|
| 感知 | 小检测器（YOLO/RT-DETR 级，几十~几百 MB，**INT8 量化**） | 无 |
| 决策 | 规则/行为树/规划器（**近零算力**，不上大模型） | 预设轨迹 + 时间同步 |
| 协同 | 协议 + 分布式算法（任务分配/去重/互为备份） | 集中编舞 |
| 硬件档位 | RK3588/算能级 < Jetson Orin Nano/NX < AGX Orin（**按需求选型**） | 普通飞控 + 同步模块 |
| 保底通信 | 4G/5G 模块 + 北斗短报文（窄带保底） | 不需要 |

**关键**：邻机“自主决策”靠**通信协议 + 分布式算法**，**不是每机塞大模型**；10B 级模型在机载跑不动实时检测。

## 4. 数据分拣 = AI 最值钱的地方

- 机载先出**结构化结果**：`{kind,confidence,u,v}` / 缺陷列表 / **关键帧**；
- 原始视频**默认不回传**，按需调取 → 单机回传带宽从 Mbps 级降到 **Kbps 级**；
- **收益估算可复现**：`python3 scripts/data-triage-bandwidth.py`（纯计算、无依赖），
  给定机数/帧率/JPEG 大小/检测框字节数，输出"原始视频 / 仅结构化 / 仅关键帧 / 混合"四档带宽、
  分拣节省百分比与链路容量适配判断。**量级估算，非实测**——真机带宽需实测标定。
- 断连期间：机载自治 + 本地存储，回连后**按优先级补传**（缺陷 > 事件 > 摘要 > 原始帧）；
- 采集量大时（多机多传感器），机载 AI **先分辨“哪些要传/哪些丢弃”**——这正是无实时链路场景下 AI 的核心价值。

## 5. 与 NexusSky 现有模块的映射（不重复造轮子）

| 能力 | 已有基础 | 本设计增量 |
|---|---|---|
| 链路质量/故障切换 | `commadapt`：AdaptiveRouter / FailoverManager / LinkQualityMonitor / SwitchDecision | 通信画像（`profile`）、分层 SLA、DTN 状态 |

| 链路仿真 | `linksim` | L0–L3 分层仿真场景 |
| 任务/调度 | `mission` / `scheduling` / `autodispatch` | 机载自治与协同的回退/接管口径 |

## 6. 评测口径（单机 + 群体）

- **单机**：识别率 / 误检比 / 处理时间（既有 `CvEvalService`）；
- **群体**：覆盖率、重复率、接管时延、断链存活率、回传带宽（**新增，待实现**）；
- **成本**：单机硬件 + 流量 + 卫星费用（量级测算，以实际采购为准）；
- **可观测性**：链路层切换次数/原因、DTN 补传时延、机载自治决策日志。

## 7. 诚实边界

- 本文是**架构与口径**，**不产生真机/真链路证据**；SLA 数字为**建议起点**，需实测标定；
- 不承诺“几百架表演 + 工业 mesh 同时全功能”——两者**控制模型不同**，统一的是通信/调度面；
- 模型选型/精度验收依赖**领域标注数据**，本文不替产品决定；性能/成本数字均为**量级**，非报价；
- 所有外部链路（4/5G、卫星）依赖真实环境与资质，非 CI 可证。
