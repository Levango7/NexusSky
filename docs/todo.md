## 怎么用这份清单

1. **先看 P0**：证据最硬、影响最直接；
2. 每条按"**改坏生产代码 ⇒ 对应用例必须红**"的方式验收（变异验证），
   否则新写的用例可能又是一个摆设；
3. 做完一条：划掉 + 写 PR 号 + 把证据补进对应门禁（让门禁以后能拦住回退）。
