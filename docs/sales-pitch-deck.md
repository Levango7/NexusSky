## 第 6 页 — 核心能力 2：应急 Mesh 自愈组网 + 星地中继（M5-M7）

**页标题**：应急通信组网 — Mesh 自愈 + 多层级中继

**核心内容**：

**M5 Mesh 自愈组网**：
- AODV-lite 多跳动态路由（RREQ/RREP/RERR），按需建路，帧级 TTL/hopCount
- 邻居超时 → 标记链路断 → 触发 RERR → 受影响节点重新 RREQ（自愈重构）
- 路由度量：跳数 × W1 + RSSI × W2 + 端到端延迟 × W3

**M6 移动基站载荷**：
- LTE micro-cell / WiFi mesh / LoRa 三种制式抽象，统一接口
- 覆盖区计算、终端接入、越区切换

**M7 多层级中继**：
- L0 地面终端 → L1 低空 mesh → L2 高空中继机 → L3 LEO 卫星 → L4 地面站
- 近端优先：L1 可达不升 L2；不可达逐级升级
- 卫星链路模型：天通/铱星/星链，按灾区位置自动选择

**关键话术**：
> "灾害场景下通信中断是常态。NexusSky 的 mesh 自愈组网让无人机群自动重构通信拓扑，星地中继让灾区信息直达指挥中心——这个能力竞品完全没有。"

**视觉建议**：
- 中心：多层级中继拓扑图（L0-L4 层级标注，无人机节点 + 卫星 + 地面站）
- 左下：AODV-lite 自愈流程图（正常 → 断链 → RERR → 重路由 → 恢复）
- 右下：Starlink 链路测试结果截图（25s 通 / 2.5s 黑洞，9.6% 丢包下任务流 PASS）
