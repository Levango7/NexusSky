## 一、定价哲学

### 1.1 核心原则：对标自研成本，而非竞品价格

NexusSky 的定价不追随市场上任何竞品的价格曲线，而是以**客户自研同等能力的总成本**为锚点，在自研成本的 10%-40% 区间定价，使客户获得"省 60%-90% 成本 + 缩短 80% 周期"的明确价值感知。

### 1.2 自研成本对标模型

| 维度 | 客户自研 | 采用 NexusSky | 节省 |
|---|---|---|---|
| **资金投入** | 500 万+（10 人团队 × 2 年，含薪资+基础设施+试错成本） | 20–200 万（按档位） | 60%-90% |
| **时间周期** | 18-24 个月（需求分析→架构设计→开发→测试→部署） | 2-3 个月（评估→POC→部署上线） | 80%-87% |
| **技术风险** | 高（多机协同、Mesh 组网、应急编排均为前沿领域，试错成本大） | 低（已有 5966 单测验证、模拟器全链路跑通） | 风险转移 |
| **人力需求** | 10+ 人（后端、前端、MAVLink 协议、运维） | 2-3 人（集成对接 + 运维） | 70%-80% |
| **持续运维** | 自建运维团队（5+ 人，年成本 100 万+） | 可选托管运维（10-30 万/年） | 70%-90% |

### 1.3 定价三原则

1. **价值定价而非成本定价**：价格反映客户获得的价值（省 300-450 万 + 快 18 个月），而非 NexusSky 的开发成本
2. **模块化阶梯而非一刀切**：客户按需选模块，从基础版 20–50 万/年到完整版 100–200 万/年，覆盖不同规模客户
3. **PoC 阶段保守定价**：真机验证完成前，完整版年费不超过 200 万/年，避免过度承诺

## 二、三档定价详细方案

### 2.1 基础版（20–50 万/年）

> **档位对照**：`docs/PRODUCT-POSITIONING.md` §5.1.1 是唯一档位 ↔ 代码模块对照入口；
> 具体费用以双方签署的商业授权合同为准，下列子档仅为交付示例。

**授权模块**：`core` + `fleet` + `mesh` + `orch`

| 模块 | 所属档位 | 覆盖能力 |
|---|---|---|
| **core** | 基础版 | 设备网关、MAVLink 协议栈、认证、遥测、围栏、RID、硬件抽象 |
| **fleet** | 基础版 | 机队注册、编队、喷洒、物流、测绘、巡检、集群调度 |
| **mesh** | 基础版 | M5 AODV-lite 自愈组网、多跳路由、链路质量评估 |
| **orch** | 基础版 | M9 应急任务编排、编排计划、四级抢占调度 |

**目标客户**：二线整机厂商、飞控厂商、轻量集成需求方

**定位**：将 NexusSky 核心协议栈与调度、组网、编排能力以 SDK 形式嵌入客户现有系统，或通过私有部署交付基础版，客户自行运维。

**交付形态与示例子档**

| 交付形态 | 子档 | 费用 | 设备上限 | API 调用上限 | 技术支持 | 适用场景 |
|---|---|---|---|---|---|---|
| SDK 授权 | 轻量档 | 20 万/年 | ≤ 20 架 | 20,000 次/天 | 邮件支持（48h 响应） | 飞控厂商评估集成、小型团队 |
| SDK 授权 | 标准档 | 30 万/年 | ≤ 50 架 | 50,000 次/天 | 邮件+电话支持（24h 响应） | 二线整机厂商、中型团队 |
| SDK 授权 | 专业档 | 45 万/年 | ≤ 100 架 | 100,000 次/天 | 专属技术顾问（8h 响应） | 飞控厂商深度集成、大型团队 |
| 私有部署 | 基础部署档 | 50–80 万/项目 | ≤ 20 架 | 20,000 次/天 | 30 天上线支持 | Docker Compose 单机，中型方案商 |

**不包含的模块**：`emergency`（升级至应急版，+4a 空地一体化应急指挥/ONVIF）、`network`+`advanced`（升级至完整版，+基站/卫星中继/数字孪生/AI）。

#### License 机制（所有档位通用）

- API Key 认证（`ns-{tenantId}-{random32chars}` 格式）
- License Key 绑定：租户 ID + 设备上限 + 模块范围 + 有效期
- RSA-SHA256 签名防篡改
- 年度续约，逾期 30 天自动降级为只读模式

### 2.3 完整版（100–200 万/年）

> **档位对照**：`docs/PRODUCT-POSITIONING.md` §5.1.1；完整版 = 应急版 + `network` + `advanced`；

**授权模块**：`core` + `fleet` + `mesh` + `orch` + `emergency` + `network` + `advanced`（全模块）

|---|---|---|

**目标客户**：大型解决方案商、eVTOL 企业

**定位**：全模块授权，可在私有环境（Docker/K8s）完全部署，并叠加行业深度定制开发、SLA 保障与专属运维团队。

**交付形态与示例子档**

| 交付形态 | 子档 | 费用 | 定制范围 | SLA | 运维 | 适用场景 |

| 私有部署 | 完整部署档 | 150–200 万/项目 | 标准模块 + Docker/K8s 多节点高可用 | 99% 可用性 | 180 天运维支持 + 月度巡检 | 大型解决方案商 |

**不包含的模块**：无（全模块）。

**License 机制**：与基础版相同，并额外绑定基站/卫星中继、数字孪生、AI 决策等高级模块的使用权；支持 SLA 条款写入商业授权合同。

#### 定制开发范围界定（仅行业定制交付形态适用）

### 6.1 POC 三阶段漏斗

```
阶段 1：免费评估          阶段 2：付费 POC           阶段 3：正式签约
```

### 6.2 阶段 1：免费评估（0 元，1-2 周）

| 项目 | 内容 |

| **目的** | 了解客户需求、技术栈匹配度、可行性评估 |

| **NexusSky 投入** | 技术方案定制、模拟器 Demo 演示 |
| **退出条件** | 客户明确无需求或技术不匹配 |
| **转化预期** | 30%-50% 进入付费 POC |

#### 免费评估内容清单

- 客户现有技术栈调研（飞控型号、通信方式、业务场景）

- 初步报价方案（推荐档位 + 模块组合 + 定制范围）

| 项目 | 内容 |
|---|---|

| **NexusSky 投入** | 技术团队驻场/远程支持、定制集成开发 |
| **退出条件** | POC 验证不通过（退还 50% 费用）或客户决定不签约 |
| **转化预期** | 60%-80% 进入正式签约 |

| **定制范围限制** | 单项目定制开发不超过 200 人天 | 控制交付风险，避免过度承诺 |

### 8.4 定价风险与应对

| 风险 | 影响 | 应对策略 |
|---|---|---|
| **客户质疑 PoC 阶段定价** | "你们连真机都没飞过，凭什么收这么多？" | 对标自研成本（500 万+ 2 年），强调省 60%-90%；提供付费 POC 降低风险 |
