## 一、定价哲学

### 1.1 核心原则：对标自研成本，而非竞品价格

NexusSky 的定价不追随市场上任何竞品的价格曲线，而是以**客户自研同等能力的总成本**为锚点，在自研成本的 10%-40% 区间定价，使客户获得"省 60%-90% 成本 + 缩短 80% 周期"的明确价值感知。

### 1.2 自研成本对标模型

| 维度 | 客户自研 | 采用 NexusSky | 节省 |
|---|---|---|---|
| **资金投入** | 500 万+（10 人团队 × 2 年，含薪资+基础设施+试错成本） | 50-200 万（私有部署版） | 60%-90% |
| **时间周期** | 18-24 个月（需求分析→架构设计→开发→测试→部署） | 2-3 个月（评估→POC→部署上线） | 80%-87% |
| **技术风险** | 高（多机协同、Mesh 组网、应急编排均为前沿领域，试错成本大） | 低（已有 3230 单测验证、模拟器全链路跑通） | 风险转移 |
| **人力需求** | 10+ 人（后端、前端、MAVLink 协议、运维） | 2-3 人（集成对接 + 运维） | 70%-80% |
| **持续运维** | 自建运维团队（5+ 人，年成本 100 万+） | 可选托管运维（10-30 万/年） | 70%-90% |

### 1.3 定价三原则

1. **价值定价而非成本定价**：价格反映客户获得的价值（省 300-450 万 + 快 18 个月），而非 NexusSky 的开发成本
2. **模块化阶梯而非一刀切**：客户按需选模块，从 10 万入门到 500 万定制，覆盖不同规模客户
3. **PoC 阶段保守定价**：真机验证完成前，定价上限不超过行业方案 500 万/项目，避免过度承诺

## 二、三档定价详细方案

### 2.1 SDK 授权版（10-30 万/年）

**目标客户**：飞控厂商、有技术团队的二线整机厂商、轻量集成需求方

**定位**：将 NexusSky 核心协议栈与调度能力以 SDK 形式嵌入客户现有系统，客户自行部署和运维。

#### 包含模块

| 模块 | 包含 | 说明 |
|---|---|---|
| **Core SDK**（Java + Python） | ✅ | 设备管理、任务上传、飞行控制、遥测查询、飞行日志 |
| **REST API 完整文档** | ✅ | OpenAPI 3.0 规范，155+ 端点 |
| **MAVLink 协议栈** | ✅ | MAVLink v1/v2 完整实现，兼容 PX4/ArduPilot |
| **基础技术支持** | ✅ | 工作日邮件/工单响应（48 小时内），季度版本更新 |

#### 不包含模块

| 模块 | 不包含 | 升级路径 |
|---|---|---|
| **集群调度**（M10） | ❌ | 升级至私有部署版 |
| **Mesh 自愈组网**（M5） | ❌ | 升级至私有部署版 |
| **应急任务编排**（M9） | ❌ | 升级至私有部署版 |
| **空地一体化应急指挥**（4a） | ❌ | 升级至行业定制版 |
| **数字孪生与预测**（M13） | ❌ | 升级至行业定制版 |
| **多层级通信中继**（M6+M7） | ❌ | 升级至私有部署版 |
| **GCS Web 地面站** | ❌ | 升级至私有部署版 |
| **Docker/K8s 部署支持** | ❌ | 升级至私有部署版 |

#### SDK 授权分档

| 档位 | 年费 | 设备上限 | API 调用上限 | 技术支持 | 适用客户 |
|---|---|---|---|---|---|
| **入门版** | 10 万/年 | ≤ 5 架 | 5,000 次/天 | 邮件支持（48h 响应） | 飞控厂商评估集成、小型团队 |
| **标准版** | 20 万/年 | ≤ 20 架 | 20,000 次/天 | 邮件+电话支持（24h 响应） | 二线整机厂商、中型团队 |

#### License 机制

- API Key 认证（`ns-{tenantId}-{random32chars}` 格式）
- License Key 绑定：租户 ID + 设备上限 + 模块范围 + 有效期
- RSA-SHA256 签名防篡改
- 年度续约，逾期 30 天自动降级为只读模式

### 4.2 大疆 Cloud API 详细对比

- 客户现有技术栈调研（飞控型号、通信方式、业务场景）

## 八、定价边界与约束

### 8.1 PoC 阶段定价约束

| 约束项 | 约束内容 | 理由 |

| **SLA 限制** | PoC 阶段 SLA 不超过 99% | 真机验证前不宜承诺过高可用性 |
| **定制范围限制** | 单项目定制开发不超过 200 人天 | 控制交付风险，避免过度承诺 |

### 8.2 真机验证后定价调整空间

| 调整维度 | PoC 阶段定价 | 真机验证后定价 | 调整方向 |

| **私有部署** | 50-200 万/项目 | 80-300 万/项目 | ↑ 30%-50%（交付信心增强） |
| **行业定制** | 100-500 万/项目 | 150-800 万/项目 | ↑ 30%-60%（案例背书溢价） |
| **SLA 承诺** | 99% | 99.5%-99.9% | ↑（真机验证后可承诺更高可用性） |

### 8.3 定价调整触发条件

| 触发条件 | 调整内容 | 预期时间 |
|---|---|---|
| **真机集群验证完成** | 全档位定价上调 30%-50% | 商用转型后 6 个月 |

### 8.4 定价风险与应对

| 风险 | 影响 | 应对策略 |
|---|---|---|
| **客户质疑 PoC 阶段定价** | "你们连真机都没飞过，凭什么收这么多？" | 对标自研成本（500 万+ 2 年），强调省 60%-90%；提供付费 POC 降低风险 |
