# 样机/真机到货前：无硬件准备与实测剧本（P1 外部条件清单）

> 适用对象：在**没有真实样机**时，先把验证边界、选型问题、台架/飞行实测步骤与证据口径固化，确保拿到设备后能快速完成"最短闭环"。
>
> 边界声明：本文档**不新增产品能力**，也**不替代真机验收**；它把既有 SITL / 协议级模拟 / 真机构分成三层证据，用于对外澄清（销售 / 招标 / 客户）**哪些是仿真或协议模拟、哪些必须真机完成**。
>
> 相关： [SITL 集成与兼容性验证](sitl-integration.md) · [集成手册](integration-guide.md) · [DJI Cloud 外部视觉](external-vision-inference.md) · [协议/厂商集成](protocol-vendor-integration.md)

## 1. 证据分层（先分清，再选机型）

| 层 | 依据 | 能证明什么 | 不能证明什么 | 适用时机 |
|---|---|---|---|---|
| L0 协议级模拟 | 官方/公开协议文档 + 仓库仿真器 / 模拟器夹具 | 解析、映射、tid 关联、状态机 / 容错、策略类软件逻辑 | 真实链路时序、真实固件行为、无线环境 | 现在（无硬件） |
| L1 SITL / 仿真飞控 | ArduPilot / PX4 SITL + NexusSky（见 sitl-integration） | 任务状态机、`MAVLink` 消息收发、指令被固件以同一套语义接收、任务上传/回读等（以 SITL 实测口径） | 气动/导航精度、传感器噪声、真实链路丢包行为 | 现在（无硬件） |
| L2 台架 / 低风险真机 | 真机 + 桨卸下/固定、悬停、受控测试 | 供电、通信、解锁/起飞/降落、失控保护配置、日志 | 长航时、现场电磁/遮挡、大范围编队与验收项 | 有设备后 |
| L3 场测 / 招标验收 | 合法空域 + 完整测试矩阵 | 指定工况下的端到端可用性与安全记录 | 超出所测工况的性能与法规结论 | 有设备后 |

> **选机优先级**：优先选 **ArduPilot / PX4 飞控 + 文档清楚、可配 MAVLink** 的整机或飞控板；只配私有 App、不开放 MAVLink 的玩具机**不适用于本项目 MAVLink 栈**。DJI Cloud API / 机巢路径需 DJI 生态设备与厂家（见 §6），丐版非 DJI 机替代不了。

## 2. 选型问题清单（买/租/借前问商家，可直接转发）

### 2.1 基本信息
- [ ] 整机/飞控型号、飞控固件类型（ArduPilot / PX4 / 私有）及版本；
- [ ] 是否明确支持 **MAVLink v2**，能否由 GCS 或板载伴飞转发成 **UDP** 给外部程序？可否设置目标 IP/端口、sysid？
- [ ] 是否有配套 **SITL**（PX4 jmavsim / ArduPilot sim_vehicle）以便与 NexusSky 回归流程一致？
- [ ] 数传/伴飞/图传链路型号，供电方式，能否在台架条件下稳定供电？
- [ ] 设备安全装置：桨卸下接口、急停/断电、失控保护（RTL / 降落 / 悬停）、地理围栏与返航阈值？

### 2.2 能力支持（逐条确认，不要口头"支持"）
- [ ] 遥测：心跳、姿态、位置、GPS/RTK 状态、电池、模式；可读字段清单（按机型/固件）；
- [ ] 指令：解锁/锁定、起飞、降落、悬停、返航、航点模式、速度/高度设置（以固件支持为准）；
- [ ] 任务：航点上传/回读/执行/清除；任务状态回调；waypoint 数量上限；
- [ ] 失控/返航：断链、低电、GPS 失效时的配置行为（**只在安全场地验证**）；
- [ ] 视觉/相机（如需）：相机触发、图传、RTK 定位/差分；（另行立项/协议，不与遥测控制混验）

### 2.3 采购/租赁交付物
- [ ] 固件镜像与版本说明、参数备份、接线/接头定义、数传配置手册；
- [ ] 测试许可（室内/空旷场地、法规合规）、保险与责任主体、紧急联络方式；
- [ ] 可远程/现场协助的工程师支持（首次上电/飞行强烈建议）。

## 3. 到货/借到后：最短实测闭环（按顺序跑）

### 0) 安全前置（未做完不得解锁飞行）
- [ ] 桨卸下或固定，断电/急停可达；操作员与观察员分工明确；场地合法空旷、无人员车辆风险；
- [ ] 配置：失控保护（断链→RTL/悬停/降落其一，按法规与场地设定）、低电保护、地理围栏、返航高度/电量阈值；
- [ ] 供电与链路确认：地面站（Mission Planner / QGroundControl 或同等）能稳定读心跳与遥测。

### 1) 台架联调（不飞行）
- [ ] NexusSky `cloud-backend` 指向该链路（示例见 [sitl-integration §4.1](sitl-integration.md#41-cloud-backend-配置)；真机用数传/伴飞地址替换 `127.0.0.1`）；
- [ ] 确认设备被识别：遥测曲线（电池/位置/模式/GPS/RTK）持续更新，无持续 MISSION_REQUEST 异常等错误；
- [ ] 指令被固件接受：解锁→拒绝非法态/成功→锁定（按固件约束验证）；
- [ ] 任务上传/回读：上传简单航点 → 回读一致 → 清除。

### 2) 第一次低风险飞行（安全场地）
- [ ] 解锁 → 起飞至低高度 → 悬停 → 降落；记录成功/失败、日志、延迟；
- [ ] 改变模式（如 LOITER/AUTO 需提前在地面设好任务）验证 `modeLabel` 与任务状态机行为；
- [ ] 返航/RTH（仅在安全条件下）验证触发与高度/电量阈值。

### 3) 任务航线（固定场景）
- [ ] 下发环形/直线航点 → 回读 → 执行 → 记录偏差、完成/失败状态；
- [ ] 围栏/低电/返航触发（受控）记录；
- [ ] 数据归档：日志、参数、链路拓扑、问题清单。

### 4) 验收/汇报
- [ ] 明确标注每项通过证据属于 L1/L2/L3 哪一层；L0/L1 不能冒充 L3；
- [ ] 不承诺未测项、未测工况；不把 PoC/仿真结论写成生产验收。

## 6. DJI 生态设备的特别说明

- 非 DJI / 不支持 DJI Cloud API 的设备**不能走 "DJI Cloud API / 机巢网关" 栈**；只能走 MAVLink（若支持）或对应厂商/私有协议路径。
- DJI 路径涉及机巢/飞机/云端协议与现场网络（EMQX 等），必须由 DJI 生态提供设备/环境与工程师支持；当前仓库实现为 `flight_task` 子集 PoC，**不承诺真机/真系统验收结论**。

---

## 7. 风险与诚实边界

- 本清单只加速"该测什么/怎么测/证据怎么写"，**不产生任何真实飞行/验收证据**；
- 任何 L3 结论必须在合法空域、按法规与安全规程、由具备资质人员在现场完成；
- SITL/协议模拟通过 = 软件逻辑正确，≠ 真机性能/合规结论。
