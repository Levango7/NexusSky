# NexusSky 天枢 — 一页纸产品介绍

> **多机协同指挥调度云平台** | 面向无人机集群的数字化协同中间件

---

## 是什么？

一套**协议中立**的无人机集群云平台，对接 PX4/ArduPilot/自研飞控，提供多机调度、自主决策、应急组网、数字孪生等上层数字化能力。

## 核心卖点

| # | 能力 | 竞品做不到的 |
|---|---|---|
| 1 | **集群智能调度** | 多机任务分配 + 冲突避免 + 损毁重分配 |
| 2 | **应急 mesh 自愈组网** | AODV-lite 路由 + 星地中继 + 移动基站 |
| 3 | **数字孪生 + 轨迹预测** | 状态镜像 + 虚实对比 + 场景回放 |
| 4 | **边缘 AI 推理** | 机载视频分析 + 传感器融合 |
| 5 | **协议中立** | 不绑大疆，兼容任意 MAVLink 飞控 |

## 技术栈

Java 17 + Spring Boot 3.5 + React 18 + MAVLink v1/v2 + Docker + K8s

## 交付方式

- **SDK 授权**：10-30 万/年（协议栈 + 技术支持）
- **私有部署**：50-200 万/项目（全模块 + 部署 + 培训）
- **行业方案**：100-500 万/项目（平台 + 定制 + 运维）
