## 一、产品定位

NexusSky（天枢）是一套面向无人机集群的**协同指挥调度云平台中间件**，提供从协议接入、多机调度、自主决策到数字孪生的全栈数字化能力。

**不是飞控系统**，而是飞控之上的"云端大脑"——对接 PX4/ArduPilot/自研飞控，输出协同调度、任务编排、应急组网等上层数字化能力。

```
┌──────────────────────────────────────────────┐
│              NexusSky 云端协同平台              │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│  │ 协同调度 │ │ 自主决策 │ │ 数字孪生 │         │
│  └─────────┘ └─────────┘ └─────────┘         │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│  │ 应急组网 │ │ 边缘计算 │ │ 链路仿真 │         │
│  └─────────┘ └─────────┘ └─────────┘         │
├──────────────────────────────────────────────┤
│           MAVLink 协议中间件 (v1/v2)            │
├──────────────────────────────────────────────┤
│     PX4 / ArduPilot / 自研飞控（客户现有）       │
└──────────────────────────────────────────────┘
```

## 三、系统架构

### 3.1 模块组成

| 模块 | 职责 | 技术栈 |
|---|---|---|
| **mavlink-core** | MAVLink 协议编解码 + 消息注册 | Java 17, 无外部依赖 |
| **drone-sim** | 虚拟无人机模拟器 + 物理引擎 + 载荷 | Java 17, 无外部依赖 |
| **cloud-backend** | 云端网关 + 协同调度 + REST API + WebSocket | Spring Boot 3.5, Java 17 |
| **link-sim** | 链路损伤代理 + mesh 中继 | Java 17 |
| **gcs-web** | 地面站前端 + 实时监控 + 任务管理 | React 18, Vite |

### 3.2 数据流

```
无人机(PX4/ArduPilot) ──MAVLink/UDP──► cloud-backend 网关
                                              │
                    ┌─────────────────────────┤
                    │                         │
              TelemetryIngestService     REST API (/api/**)
              (帧分发 + 路由)            (Swagger 文档)
                    │                         │
         ┌─────────┼─────────┐         WebSocket (/ws/**)
         │         │         │         (实时推送)
    DeviceRegistry  │   MissionMgr
    (设备状态)      │   (任务管理)
                    │
         ┌─────────┼─────────┐
         │         │         │
    Scheduling  Decision  DigitalTwin
    (集群调度)  (AI决策)   (数字孪生)
```

### 3.3 部署架构

- **单机部署**：docker-compose 一键启动（cloud + sim + web）
- **K8s 部署**：Helm chart，支持多副本 + 滚动升级 + 健康检查
- **混合部署**：边缘节点运行 drone-sim，云端运行 cloud-backend + gcs-web

## 四、差异化优势

### 4.1 对比大疆 Cloud API

| 维度 | 大疆 Cloud API | NexusSky |
|---|---|---|
| 定位 | 大疆设备专属 | **协议中立**，兼容 PX4/ArduPilot/自研飞控 |
| 多机协同 | 基础编队 | **集群智能调度** + 冲突避免 + 任务重分配 |
| 应急组网 | 无 | **AODV-lite mesh 自愈** + 星地中继 |
| 数字孪生 | 无 | **状态镜像** + 轨迹预测 + 场景回放 |
| 边缘计算 | 无 | **边缘节点** + 传感器融合 |

### 4.2 对比 PX4 SDK / MAVProxy

| 维度 | PX4 SDK / MAVProxy | NexusSky |
|---|---|---|
| 定位 | 单机开发工具 | **多机协同云平台** |
| 任务编排 | 基础航点 | **应急全流程编排** + 覆盖优化 |
| 可观测性 | 日志文件 | **Prometheus 指标** + 健康检查 + 结构化日志 |
| 部署 | 命令行 | **Docker + K8s** + Helm |

### 4.3 核心差异化

1. **协议中立**：不绑大疆/PX4，MAVLink 标准协议对接任意飞控
2. **多机协同**：集群调度 + 冲突避免 + 任务重分配，竞品做不深
3. **应急组网**：mesh 自愈 + 星地中继 + 移动基站，灾害场景独有能力
4. **数字孪生**：状态镜像 + 轨迹预测 + 虚实对比，可服务于适航验证

## 八、边界声明

本系统遵循"软件协议层先行、数据源可替换"原则：

- **已实现**：协议抽象 + 模拟器数据源 + 云端协同调度 + 全栈工程化
- **需客户对接**：真硬件数据源替换（飞控/雷达/传感器），架构不变只需替换数据源
- **不在范围**：飞控核心算法（PID/EKF）、适航认证、真机飞行验证
