## 二、行业解决方案商（优先级 ⭐⭐⭐）

### 1. 航天宏图信息技术股份有限公司（PIESAT）
- **定位**：遥感测绘行业解决方案商，卫星+无人机
- **痛点**：多机协同测绘效率低，覆盖规划靠人工
- **NexusSky 切入点**：M10 集群调度 + M9 覆盖优化 + M3 多光谱成像
- **采购流程**：上市公司，有技术研发团队，可接受私有部署
- **预估价值**：100-300 万/项目

### 2. 中科龙智科技有限公司
- **定位**：无人机行业应用解决方案，军警民用
- **痛点**：多机协同指挥能力不足，应急通信组网缺失
- **NexusSky 切入点**：M5 mesh 自愈组网 + M9 应急编排 + M10 集群调度
- **采购流程**：有军方渠道，重视国产自主可控
- **预估价值**：200-500 万/项目

### 3. 大工（大连）无人机科技有限公司
- **定位**：工业无人机解决方案，电力/安防/测绘
- **痛点**：多机分工巡检缺乏统一调度平台
- **NexusSky 切入点**：M10 集群调度 + M11 自主决策 + M13 数字孪生
- **采购流程**：中小型公司，决策快，可接受 SDK 授权
- **预估价值**：50-100 万/项目

### 4. 成都纵横自动化技术股份有限公司
- **定位**：工业级垂直起降固定翼无人机（已上市）
- **痛点**：单机能力强但多机协同弱，缺云端调度
- **NexusSky 切入点**：M10 集群调度 + M13 数字孪生 + GCS 地面站
- **采购流程**：上市公司，有研发团队，可深度合作
- **预估价值**：100-200 万/项目

### 5. 深圳市智航无人机有限公司
- **定位**：工业级多旋翼无人机，测绘/安防/植保
- **痛点**：行业应用碎片化，缺统一协同平台
- **NexusSky 切入点**：M2 喷洒物流 + M10 集群调度 + M4 硬件抽象
- **采购流程**：中小型公司，可接受 SDK 授权或 SaaS
- **预估价值**：30-80 万/项目

## 三、eVTOL 企业（优先级 ⭐⭐⭐）

### 6. 亿航智能（EHang）
- **定位**：载人级自动驾驶飞行器，已获型号合格证
- **痛点**：适航验证需要大量仿真数据，数字孪生可降低验证成本
- **NexusSky 切入点**：M13 数字孪生 + 轨迹预测 + 场景回放（适航验证服务）
- **采购流程**：上市公司，研发能力强，可能自研，需找差异化切入点
- **预估价值**：100-300 万（适航验证工具）

### 7. 峰飞航空科技（VolkFlight）
- **定位**：大型 eVTOL，货运+载人
- **痛点**：多机运营调度平台缺失
- **NexusSky 切入点**：M10 集群调度 + M13 数字孪生 + M7 星地中继
- **采购流程**：初创期，有融资，技术导向
- **预估价值**：50-150 万/项目

### 8. 沃飞长空（Aerofugia）
- **定位**：吉利旗下 eVTOL，载人飞行汽车
- **痛点**：运营期多机调度 + 低空通信组网
- **NexusSky 切入点**：M10 集群调度 + M6 移动基站 + M8 地形适配
- **采购流程**：大企业孵化，决策链长但预算充足
- **预估价值**：100-200 万/项目

- **预估价值**：200-500 万/项目（通过集成商）

## 七、接触策略建议

### 第一阶段（1-2 周）：广撒网
- 向上述 15 家发送技术白皮书 + 一页纸产品介绍
- 重点跟进 ⭐⭐⭐ 客户（8 家）
- 目标：获得 3-5 家技术交流机会

### 第二阶段（2-4 周）：深交流
- 对有意向的客户做技术演示（3 机模拟协同 Demo）
- 了解客户现有技术栈和集成需求
- 评估定制化工作量

### 第三阶段（1-2 月）：签合同
- 对最匹配的 1-2 家做 POC（概念验证）
- 报价 + 谈判 + 签约

### 关键话术
- **不要说**："我们卖飞控系统" → 客户会问"飞过真机吗"
- **应该说**："我们卖多机协同调度云平台，对接你们现有的 PX4/ArduPilot 飞控"
- **强调差异化**：应急组网 + 数字孪生 + 集群调度，这些大疆/PX4 做不深

| 风险 | 应对 |
